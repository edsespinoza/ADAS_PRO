API Reference

Documentação completa da API REST da plataforma ADAS PRO. Acesse conteúdo técnico, gerencie progresso e certificações.

v1.0.0 Stable Base URL: /functions/v1
🔐

Autenticação

API Key ou JWT Bearer Token. Obrigatório para todos os endpoints.

⚡

Rate Limit

100 requisições por minuto por chave de API ou token JWT.

🔒

HTTPS

Todas as requisições devem usar HTTPS. HTTP é rejeitado automaticamente.

Autenticação

A API suporta dois métodos de autenticação. Passe um deles no cabeçalho de cada requisição.

Gerada no painel de controle em Configurações → API Keys. Passe no cabeçalho X-API-Key.

HTTP Header 
X-API-Key: adas_live_xxxxxxxxxxxxxxxxxxxx

Token JWT obtido via supabase.auth.signInWithPassword(). Passe no cabeçalho Authorization.

HTTP Header 
Authorization: B eyJhbGciOiJIUzI1NiIs...

Rate Limiting

⚡

100 requisições / minuto

Limite por API Key ou JWT. Cabeçalhos de resposta indicam o estado atual.

Cada requisição retorna os seguintes cabeçalhos de rate limit:

Response Headers 
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 87
X-RateLimit-Reset: 1703001660

Tratamento de Erros

Todas as respostas de erro seguem o formato padrão:

ErrorResponse
ok boolean Sempre false em erros
error string Mensagem descritiva do erro
code string Código de erro para tratamento programático

Principais códigos de erro:

HTTP Status Codes
401  UNAUTHORIZED          Credenciais ausentes ou inválidas
403  FORBIDDEN              Permissão insuficiente para este recurso
404  NOT_FOUND              Recurso não encontrado
429  RATE_LIMITED           Limite de requisições excedido
500  INTERNAL_ERROR         Erro interno do servidor

Paginação

Endpoints de listagem suportam paginação via query params page e per_page.

PaginatedResponse
ok boolean true
data array Lista de itens
total integer Total de itens disponíveis
page integer Página atual (1-indexed)
per_page integer Itens por página (máx. 100)

          POST
          /api/v1/certifications/:id/quiz
          Iniciar/enviar quiz de certificação
          
        

        

          
Inicia um quiz ou envia respostas para avaliação. Para iniciar, envie apenas o moduleId. Para enviar respostas, inclua o array answers.

          
Request Body

          

            

              moduleId
              string
              Obrigatório. ID do módulo
            

            

              answers
              array
              Array de respostas (opcional — vazio = iniciar quiz)
            

          

          

            

              cURL
              
            

            
curl -X POST https://zqydyyticvtmirjzskly.supabase.co/functions/v1/api-gateway \
  -H "Content-Type: application/json" \
  -H "X-API-Key: adas_live_xxx" \
  -d '{
    "action": "submit_quiz",
    "certificationId": "cert-level-1",
    "moduleId": "mod-1-1",
    "answers": [
      { "questionId": "q1", "selected": "a" },
      { "questionId": "q2", "selected": "c" }
    ]
  }'

JavaScript / Node.js

      

        

          JavaScript
          
        

        
const ADAS_API = 'https://zqydyyticvtmirjzskly.supabase.co/functions/v1/api-gateway';

async function listContent(category) {
  const params = new URLSearchParams({ action: 'list_content' });
  if (category) params.set('category', category);

  const res = await fetch(`${ADAS_API}?${params}`, {
    headers: { 'X-API-Key': 'adas_live_xxx' }
  });
  return res.json();
}

async function downloadContent(contentId) {
  const res = await fetch(ADAS_API, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'adas_live_xxx'
    },
    body: JSON.stringify({ action: 'get_download_url', contentId })
  });
  return res.json();
}

import requests

ADAS_API = "https://zqydyyticvtmirjzskly.supabase.co/functions/v1/api-gateway"
API_KEY = "adas_live_xxx"

def list_content(category=None):
    params = {"action": "list_content"}
    if category:
        params["category"] = category
    return requests.get(
        ADAS_API,
        params=params,
        headers={"X-API-Key": API_KEY}
    ).json()
