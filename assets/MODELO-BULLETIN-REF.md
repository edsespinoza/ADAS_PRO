## Estrutura do Modelo CNJ (newsletter/magazine)

### 1. Header
- Número do boletim (#182) + Data
- Título "BOLETIM TÉCNICO"
- Logos: Realização / Apoio

### 2. Artigo Principal (Hero)
- Headline grande + foto
- Corpo com 2-3 parágrafos explicativos
- Texto informativo, linguagem acessível

### 3. Boxes de Funcionalidades (Grid 3 colunas)
- Ícone + Título + Descrição curta
- Cards com borda lateral colorida
- Ex: "Remessa de Ofícios", "Cartas Precatórias", "Declínio de Competência"

### 4. Estatísticas (Números grandes)
- Números grandes + rótulo + nota
- Ex: "551.376 investigações", "24.271 usuários", "30,4 por usuário"

### 5. Artigos Secundários (Grid 2 colunas)
- Cards menores com ícone + título + resumo
- Notícias breves sobre outros temas

### 6. Eventos / Próximos
- Card com box de data (dia + mês) + título + descrição

### 7. Cobertura / Mídia
- Referências a matérias em outros portais

### 8. Créditos / Rodapé
- Equipe editorial, revisão, contato
- Aviso de uso interno
