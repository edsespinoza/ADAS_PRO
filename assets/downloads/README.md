# ADAS PRO — Estrutura de Downloads

Cada subpasta corresponde a uma categoria de conteúdo da plataforma.

## Estrutura
```
downloads/
  demo/          → Materiais de demonstração (acesso Free)
  honda/         → Honda & Acura (Plano Pro+)
  toyota/        → Toyota & Lexus (Plano Pro+)
  nissan/        → Nissan & Infiniti (Plano Pro+)
  subaru/        → Subaru EyeSight (Plano Pro+)
  hyundai/       → Hyundai & Kia (Plano Pro+)
  vag/           → VAG — Audi/VW/Seat (Plano Premium)
  mercedes/      → Mercedes-Benz (Plano Premium)
  ford/          → Ford & Lincoln (Plano Premium)
  radar/         → Radar Universal (Plano Premium)
  mazda/         → Mazda AVM 360° (Plano Premium)
  mitsubishi/    → Mitsubishi (Plano Premium)
  chineses/      → BYD / Chery / MG (Plano Premium)
```

## Níveis de acesso
- **Nível 1 (Free)** — apenas demo
- **Nível 2 (Módulo)** — categoria comprada individualmente
- **Nível 3 (Pro)** — honda, toyota, nissan, subaru, hyundai
- **Nível 4 (Premium)** — todas as categorias

## Instruções para substituir placeholders
Substitua os arquivos `.pdf` pelos PDFs reais mantendo os mesmos nomes de arquivo.
