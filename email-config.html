Guia de Deploy
Passos para ativar os emails em produção
1
Criar conta e chave no Resend
Acesse resend.com, crie uma conta gratuita e gere uma API Key em API Keys → Create API Key. Copie a chave (re_xxxx...) e salve no campo acima.
2
Verificar domínio adaspro.com.br no Resend
Em Domains → Add Domain, adicione adaspro.com.br. O Resend fornecerá registros DNS (TXT + DKIM + MX). Adicione-os no painel do seu provedor de domínio. Aguarde propagação (até 48h).
3
Configurar env vars na Edge Function
No Supabase Dashboard: Edge Functions → notify → Secrets, adicione: RESEND_API_KEY = re_xxxxxxxxxxxxxxxxxxxxxx ADMIN_EMAIL = superadmin@adaspro.com.br SITE_URL = https://adaspro.com.br
4
Re-deploy da Edge Function (template redesenhado)
O template HTML foi redesenhado em 2026-04-30. Execute o deploy para aplicar: supabase functions deploy notify --project-ref zqydyyticvtmirjzskly
5
Testar os 3 eventos em produção
Após o deploy, ative Modo Online nesta página e use o Painel de Teste para disparar cada evento real. Verifique a inbox do admin e dos usuários demo.

Sequência recomendada: new_user → user_approved → ticket_reply
Requer credenciais salvas e Supabase configurado
